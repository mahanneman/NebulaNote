# نبولا نوت (Nebula Note)

**دستیار یادداشت شناور و ثبت ورودی مدرن**

نبولا نوت یک ابزار سبک دسکتاپ برای یادداشت سریع، ضبط ماکرو و خروجی جلسه است. به صورت پنجره جمع‌وجور همیشه بالای صفحه اجرا می‌شود؛ شورتکات سراسری، آیکون مثلثی شناور، پیش‌نمایش زنده و خروجی چندفرمتی دارد.

> سازنده: **ma.ad.gh mahanneman**  
> مخزن: [github.com/mahanneman/cosmic-keylogger](https://github.com/mahanneman/cosmic-keylogger)

---

## امکانات

### یادداشت‌برداری
- پنجره شناور با تم تیره و همیشه بالا
- تایپ بومی با پشتیبانی کامل یونیکد (از جمله فارسی راست‌چین)
- سیستم الگوها (Snippets) با قالب سفارشی و **Ctrl+Shift+1 / 2 / 3** (و نوم‌پد)
- درج سریع: خط جداکننده، تاریخ، ساعت، نقطه، برچسب لاگ
- ذخیره خودکار، مرور فایل‌ها، کپی فایل، باز کردن پوشه
- جستجو و جایگزین، واگرد/ازنو، کپی/برش/چسباندن

### ضبط و ماکرو
- **حالت تایپ** — ثبت متن برای یادداشت
- **حالت ماکرو** — ضبط کیبورد + ماوس (کلیک / حرکت اختیاری / اسکرول)
- پشتیبانی از کلیدهای NUM PAD
- پخش با تنظیمات: تعداد تکرار، تأخیر شروع، سرعت، استراحت بین دورها، رد سکوت‌های بلند
- تایمر روی صفحه هنگام پخش
- توقف با **ESC** یا **Ctrl+Shift+Esc**

### آیکون شناور
- مثلث قابل جابه‌جایی با درگ
- کلیک چپ ← بازگرداندن پنجره اصلی
- راست‌کلیک: ضبط، ذخیره، الگوها، خروجی، پخش، راهنما، تنظیمات

### پیش‌نمایش زنده (Live Preview)
- پنجره کوچک همیشه بالا
- اسکرول خودکار به **آخرین خطوط** (پیام جدید)

### فرمت‌های خروجی
| فرمت | کاربرد |
|------|--------|
| JSON / JSONL | داده کامل رویدادها |
| Excel (.xlsx) | تحلیل در صفحه گسترده |
| CSV | جدول عمومی |
| HTML | گزارش قابل اشتراک |
| Markdown | مستندات |
| متن ساده | فقط کاراکترها |
| پایتون + **.bat** | اجرای یک‌کلیکه (سؤال تعداد دور / تأخیر / سرعت) |
| AutoHotkey (.ahk) | اجرا بدون پایتون (در صورت نصب AHK) |
| PowerShell (.ps1) | اسکریپت ویندوز |
| خلاصه جلسه | آمار و کلیدهای پرکاربرد |
| JSON رمزنگاری‌شده | خروجی محافظت‌شده |

### سایر
- رابط چندزبانه: فارسی، انگلیسی، عربی، آلمانی، فرانسوی
- سینی سیستم، ذخیره تنظیمات (`settings.json`)
- تأیید قبل از تعویض حالت / خروج (امکان ذخیره)
- لاگ کرش در `~/CosmicKeylogger/`

## پیش‌نیازها

- **پایتون 3.8 به بالا**
- ویندوز توصیه‌شده (شورتکات سراسری و سینی عمدتاً روی ویندوز تست شده)

```bash
pip install pynput pystray Pillow pandas openpyxl
```

```bash
py -m pip install pynput pystray Pillow pandas openpyxl
```

## شورتکات‌های اصلی

همه با **Ctrl+Shift** هستند مگر خلافش گفته شود.

| کلید | عمل |
|------|-----|
| **Q** | شروع / توقف ضبط |
| **W** | ذخیره |
| **E** | تعویض تایپ ↔ ماکرو |
| **A** | همیشه بالا |
| **Z** | پخش ماکرو |
| **X** | حالت شناور (مثلث) |
| **C** | پاک کردن |
| **S** | مدیریت الگوها |
| **F** | فایل‌ها |
| **G** | خروجی |
| **H** | راهنما |
| **K** | تنظیمات |
| **1 / 2 / 3** | سه الگوی سریع |
| **Ctrl+1 … 9** | درج سریع (خط، تاریخ، ساعت و …) وقتی پنجره فوکوس دارد |
| **ESC** | توقف پخش ماکرو |

## محل داده‌ها

```
~/CosmicKeylogger/
  ├── settings.json
  ├── crash.log
  └── یادداشت‌ها / خروجی‌ها (پیش‌فرض)
```
