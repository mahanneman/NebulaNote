# نبولا نوت (Nebula Note)

**دستیار یادداشت شناور و ثبت ورودی مدرن**

نبولا نوت یک ابزار سبک دسکتاپ برای یادداشت سریع، ضبط ماکرو و خروجی جلسه است. به صورت پنجره جمع‌وجور همیشه بالای صفحه اجرا می‌شود؛ شورتکات سراسری، آیکون مثلثی شناور، پیش‌نمایش زنده و خروجی چندفرمتی دارد.

## امکانات

### یادداشت‌برداری
- پنجره شناور با تم تیره و همیشه بالا
- تایپ بومی با پشتیبانی کامل یونیکد (از جمله فارسی راست‌چین)
- سیستم الگوها با قالب سفارشی و **Ctrl+Shift+1 / 2 / 3** (و نوم‌پد)
- درج سریع: خط جداکننده، تاریخ، ساعت، نقطه، برچسب لاگ (**Ctrl+1 … 9** وقتی پنجره فوکوس دارد)
- ذخیره خودکار، مرور فایل‌ها، کپی فایل، باز کردن پوشه
- جستجو و جایگزین، واگرد/ازنو، کپی/برش/چسباندن
- تأیید قبل از تعویض حالت یا خروج تا کارتان ناخواسته از بین نرود

### ضبط و ماکرو
- **حالت تایپ** — نوشتن عادی (چیدمان کیبورد ویندوز رعایت می‌شود)
- **حالت ماکرو** — ضبط کیبورد + ماوس (کلیک / حرکت اختیاری / اسکرول)
- پشتیبانی از NUM PAD
- دیالوگ پخش: تعداد تکرار، تأخیر شروع، سرعت، استراحت بین دورها، رد سکوت‌های بلند، سقف زمان
- تایمر هنگام پخش
- توقف با **ESC** یا **Ctrl+Shift+Esc** (حتی در شمارش معکوس شروع)
- با Start جدید، جلسه قبلی آرشیو می‌شود تا متن قدیمی از بین نرود

### آیکون شناور
- مثلث قابل جابه‌جایی با درگ
- کلیک چپ ← بازگشت به پنجره اصلی (حتی اگر دیالوگی باز بوده باشد)
- راست‌کلیک: ضبط، ذخیره، الگوها، خط/تاریخ/ساعت، خروجی، پخش، راهنما، تنظیمات

### پیش‌نمایش زنده
- پنجره کوچک همیشه بالا
- اسکرول خودکار به **آخرین خطوط**

### سایر
- رابط چندزبانه: فارسی، انگلیسی، عربی، آلمانی، فرانسوی
- منوی سینی سیستم
- ذخیره تنظیمات در `settings.json`
- لاگ کرش در صورت خطای غیرمنتظره

## پیش‌نیازها

### سیستم
| مورد | توضیح |
|------|--------|
| سیستم‌عامل | **ویندوز 10/11** توصیه‌شده (شورتکات سراسری، سینی، اجرای `.bat`) |
| پایتون | **۳٫۸ به بالا** (۳٫۱۰+ بهتر است) |
| نمایشگر | هر رزولوشن؛ پنجره جمع‌وجور و قابل تغییر اندازه است |
| دسترسی | برای شورتکات سراسری پایدار، در صورت نیاز **اجرا با Administrator** |

### بسته‌های پایتون

| بسته | کاربرد |
|------|--------|
| `pynput` | ضبط کیبورد/ماوس و شورتکات سراسری |
| `pystray` | آیکون سینی سیستم |
| `Pillow` | تصویر آیکون |
| `pandas` | خروجی اکسل |
| `openpyxl` | نوشتن فایل `.xlsx` |

اختیاری:
- **AutoHotkey** — فقط اگر خروجی `.ahk` را اجرا می‌کنید
- **PowerShell** — برای خروجی `.ps1` (معمولاً از قبل روی ویندوز هست)

## نصب

1. [پایتون](https://www.python.org/downloads/) را نصب کنید و گزینه **Add Python to PATH** را فعال بگذارید.
2. پاورشل یا CMD را باز کنید:

```bash
py -m pip install --upgrade pip
py -m pip install pynput pystray Pillow pandas openpyxl
```

یا با `pip`:

```bash
pip install pynput pystray Pillow pandas openpyxl
```

3. مخزن را دانلود یا کلون کنید و فایل اصلی برنامه (مثلاً `NebulaNote_Final.py`) را در پوشه دلخواه بگذارید.

---

## اجرا

```bash
py NebulaNote_Final.py
```

**نکات**
- اگر شورتکات‌ها کار نکردند، ترمینال را **با دسترسی Administrator** باز کنید و دوباره اجرا کنید.
- در اولین اجرا ممکن است فایل تنظیمات/لاگ در پروفایل کاربر ساخته شود.
- برای **Ctrl+1 … 9** پنجره برنامه باید فوکوس داشته باشد.

## شورتکات‌های اصلی

شورتکات‌های اصلی با **Ctrl+Shift** هستند مگر خلافش گفته شود.

| کلید | عمل |
|------|-----|
| **Q** | شروع / توقف ضبط |
| **W** | ذخیره |
| **E** | تعویض تایپ ↔ ماکرو |
| **A** | همیشه بالا |
| **Z** | پخش ماکرو |
| **X** | حالت شناور (مثلث) |
| **C** | پاک کردن |
| **S** | مدیریت الگوها |
| **F** | فایل‌ها |
| **G** | خروجی |
| **H** | راهنما |
| **K** | تنظیمات |
| **1 / 2 / 3** | سه الگوی سریع (با نوم‌پد هم) |
| **Ctrl+1 … 9** | درج سریع وقتی پنجره فوکوس دارد |
| **ESC** | توقف پخش ماکرو |

## نحوه استفاده

1. **یادداشت** — در کادر اصلی بنویسید؛ از الگوها و درج سریع استفاده کنید.
2. **ماکرو** — حالت ماکرو → Start → کارها را انجام دهید → Stop.
3. **پخش** — Replay را باز کنید، دور/تأخیر/سرعت/استراحت را تنظیم کنید، Start؛ با ESC قطع کنید.
4. **فایل یک‌کلیکه** — خروجی → پایتون دابل‌کلیک → اجرای `.bat` (اول تنظیمات را می‌پرسد).
5. **شناور** — Ctrl+Shift+X یا دکمه مثلث؛ کلیک روی مثلث برای بازگشت.

## تنظیمات و فایل‌ها

- تنظیمات برنامه در **`settings.json`** ذخیره می‌شود (با اولین اجرا ساخته می‌شود).

## رفع اشکال

| مشکل | کار پیشنهادی |
|------|----------------|
| شورتکات‌ها کار نمی‌کنند | اجرا با Administrator؛ بستن برنامه‌هایی که همان کلیدها را گرفته‌اند |
